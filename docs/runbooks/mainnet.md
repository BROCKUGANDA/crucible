# Mainnet launch runbook (gates G-800 to G-804) 
Status: NOT READY until node scripts/mainnet-preflight.mjs exits 0. The current tree deliberately has unsigned audit, legal, genesis, timelock, monitoring and treasury sign-offs in docs/mainnet, and no approved production Treasury Safe, Owner Safe or mainnet RPC configuration. A red preflight is the correct answer, not a bug to re-run past. 
## Order of operations 
1. Freeze the deploy commit. Run npm run verify:all, forge build sizes, forge test, coverage gate, slither triage, audit gate. Record the commit in docs/mainnet/audit-signoff.json. 
2. External audit (G-800) of CrucibleTrials, Arena, ArgusCourt and RewardMath at that exact commit. Any code change after the report restarts this step. Fill auditor, reportHash, commit, signed true. 
3. Legal package (G-803): entity formed, counsel named, ToS and privacy versions pinned, license audit filed. This file is a checklist, not legal advice. 
4. Treasury and owner custody (ADR-0020): create a dedicated company Treasury Safe and a separately controlled Owner Safe, each with the approved 2-of-3 pilot configuration. Record the Safe singleton/proxy bytecode hashes, owner set, threshold, modules, guard, module guard and fallback handler in docs/mainnet/treasury.json. The legacy escrow's treasury is immutable and withdraw() pays msg.sender's own credit back to msg.sender. Deploy the escrow with the Treasury Safe as constructor treasury. The current CrucibleTrials constructor sets owner = msg.sender and has no ownership-transfer function: the ordinary EOA deploy script does not satisfy the Owner Safe requirement. Do not claim readiness until an audited and tested deployment path makes owner() equal the approved Owner Safe. Any future parameter or upgrade path sits behind at least 48h timelock. Record multisig address, signers and timelockHours. 
5. Genesis cohort (G-804) and progressive exposure (G-801): named sponsors and agents, epoch 0 cap in ETH in genesis-cohort.json. Caps raise only after a clean epoch: zero conservation failures, zero missed settlements, audit findings closed. Lowering a cap needs no waiting period; raising one always does. 
6. Monitoring and on-call (G-802): conservation invariant balance check per block batch, settlement lag, indexer syncError, fee versus treasury credit reconciliation, keeper and warden heartbeats. Named on-call human and alert channel in monitoring.json before any ETH moves. 
7. Deploy rehearsal on a mainnet fork: `npm run fork:test`, which tries `MAINNET_RPC_URL` and then `MAINNET_RPC_FALLBACK_URL`. Both must be ARCHIVE endpoints at the pinned block. A chain-id-1 node that prunes history is not enough: on 2026-10-26 publicnode reported chain id 1 but failed the fork in `setUp` with `historical state ... is not available`, while drpc served the pinned block and all four fork tests passed. Then GoldenPath begin and finish, withdraw from the pull ledger as each party. Settlement never pushes ETH (ADR-0003); recipients withdraw. 
8. Preflight: MAINNET_RPC_URL set to an archive chain-id-1 endpoint, TRIALS_ADDRESS pinned to the approved CrucibleTrials address, and (only when enabled) ARENA_ADDRESS pinned too. node scripts/mainnet-preflight.mjs must exit 0. It verifies Safe proxy/singleton bytecode, 2-of-3 owners, empty modules and extension slots, plus each escrow's runtime bytecode, treasury() and owner() against treasury.json and the audited commit. After deployment, run the post-deploy assertion in strict custody mode: EXPECTED_TREASURY_ADDRESS=<approved Safe> EXPECTED_OWNER_ADDRESS=<approved Safe> REQUIRE_EXPECTED_CUSTODY=1 sh scripts/assert-deployment.sh from crucible-contracts/. Then verify source, seed epoch 0 only, and watch one full trial lifecycle before raising any cap. 
## Hard rules that do not bend at mainnet 
- Fee is FEE_BPS 500, 5 percent, from the v1 escrow at settlement (ADR-0001). The v2 arena fee_bps 1500 in params is a separate ADR-0011 law and must never be read as the escrow fee. 
- Conservation is an exact equality: escrow balance equals totalStakes plus totalPending plus escrowed. Any red there stops everything; never re-run hoping for green. 
- The API holds no chain key (ADR-0006). The indexer is in-memory (ADR-0008). Keys live only with the parties who sign.
- The treasury address and on-chain transactions are public. A Safe protects signing authority; it does not hide its address, balance, credits or withdrawals. No seed phrase or private key belongs in the app, API, CI, logs or Git.
- Never use a backend signer, arbitrary withdrawal recipient or treasury redirect function. The company Safe itself must call withdraw() and receive its own credit. 
- Incident: pause new trial intake at the product layer, keep finalize and reclaimExpired permissionless so escrowed parties can always exit, page on-call, write the HARDENING entry before resuming.
