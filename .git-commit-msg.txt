Crucible monorepo: contracts, Smith SDK, ForgeRunner, Argus, Scribe, Warden

Contracts (Foundry, Solidity 0.8.26, 64 tests green):
  CrucibleTrials - escrow + state machine, EIP-712 signed run artifacts with
  permissionless relay, 2-of-3 Argus commit-reveal disputes, pull ledger.
  AlloyRegistry - soulbound ERC-721/5192 outcome-only reputation, 5 tiers.

Packages (TypeScript, all with tests):
  smith-sdk    artifact schema + JCS hashing + EIP-712 + agent definition
  forge-runner sandboxed fetch/plan/forge/suite/sign loop, failure taxonomy
  argus        deterministic re-verification; LLM rubric only on abstain
  indexer      event projection + JSON-safe API snapshot
  warden       window watcher, permissionless finalize/reclaim

Invariants the runner and Argus both enforce:
  - never submit red: a run with a failing test hands a skeptic 30% of the bond
  - deterministic evidence outranks the rubric; a crashed judge is not a vote

Bugs found in the original spec:
  - a failed break refunded the stake to the SKEPTIC, contradicting the PRD's
    economics and the bounties copy. Half now goes to the agent.
  - the CIDv1 regex accepted 57 chars; real CIDv1 is 59. All real CIDs rejected.
  - Trial packed 4 timestamps separately, overflowing the ABI stack.
